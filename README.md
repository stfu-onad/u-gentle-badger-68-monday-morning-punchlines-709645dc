# Monday Morning Punchlines

Entry for the make.fun bounty
[u-gentle-badger-68-monday-morning-punchlines-709645dc](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc)

`main.py` (Python 3.13, standard library only) writes one single-line
joke about Monday mornings to `/output/entry.txt`. The joke skips the
worn Monday moves (alarm, snooze, coffee, "I hate Mondays") and turns
getting up into a custody hearing instead: the bed files for custody
and wins, so staying in bed is legally binding. Setup and punch land
inside the one line, in one breath.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
